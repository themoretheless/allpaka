Правила оценки

  
Сохраните правило и явно включите его. Модельная проверка запускается только после передачи текста для выбранной трассы.

  
  
  
  

    

    
    
После включения правила переданный текст будет отправляться выбранному провайдеру. Действуют его условия и стоимость запросов.

  

  
  

  
  



  
  
Текст для оценки качества

  
Трасса хранит только сведения о выполнении. Здесь вы явно сохраняете текст отдельно. Выбранные модельные правила могут отправить его настроенному провайдеру для платной проверки.

  
  
  
  
  



  
  
Модельные оценки

  
Модель оценивает явно сохранённый текст. Балл не подтверждает фактическую правильность ответа. Прерванные задания автоматически не повторяются.

  
  



  
  
Очередь оценок

  
Задания выбранных правил выполняются в фоне. Проверка успешности шагов не подтверждает качество ответа.

  
  



  
  
Сводка callback-оценок

  
Оценки сообщены вашим кодом. Разные версии оценщиков учитываются отдельно; автоматического решения о качестве нет.

  
  
  
  



  
  
Память проекта

  
Сохранённые решения доступны агенту через поиск памяти. Просроченные и убранные записи не участвуют в поиске.

Пробный запуск отправит вопрос и контекст выбранной модели и сохранит пример, ответ и журнал вызовов. Оценки вычисляются только для выбранных ниже метрик.

    
Метрики пробного запуска
      
      
      
      
      
      
      
      
      
Без метрик сохраняется пробный ответ без оценки качества. Все метрики, кроме проверки корректности JSON, требуют эталонного ответа.

    

    
    

  

  

  
  
{{input}} — вопрос из примера; {{contexts}} — его справочные материалы.

  
  
  
  
  
  
  
F1 слов учитывает повторения слов; F1 символов — соседние пары символов. Обе метрики сохраняют регистр и пунктуацию. Структурное сравнение JSON игнорирует оформление и порядок ключей.
