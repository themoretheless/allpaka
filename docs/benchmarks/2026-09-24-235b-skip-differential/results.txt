# because the only other group that would have removed work - qkv - was a no-op.

# up for the real routing. Consequence for the probe as an instrument: skipping
# any group that feeds an indexed gather does not isolate that group, it
# corrupts the group downstream. `experts` is safe only because with the experts
# gone no gather happens at all.
#

# guards were simply newer than the binary: probe_skip("qkv")/("head") sit in the

# uncommitted diff that this shared worktree carries. So the guards were in the
# binary; what was wrong was the inference from the counter (see 1).
#
# 7. What the residue question should use next, in cost order. ALLPAKA_DECODE_SPLIT
# is present in this same binary (verified with strings) and its per-stage GPU

# Verdict on the pre-registered fork: NOT RESOLVED on this model. What is
